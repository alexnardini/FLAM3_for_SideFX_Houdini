### FLAM3H™ Houdini Desktops ###

Those files are Houdini Desktops you can load to better experience **FLAM3H™**.
You need to copy those files inside: `$HOME/houdini‹X›.‹Y›/desktop/` (where ‹X›.‹Y› is the version number of Houdini).
